# DIN & BST on KuaiRand-1K with FuxiCTR

End-to-end pipeline for training and evaluating **DIN** (Deep Interest Network)
and **BST** (Behaviour Sequence Transformer) on the **KuaiRand-1K** dataset using
[FuxiCTR](https://github.com/reczoo/FuxiCTR).

## Quick start

### 1  Download KuaiRand-1K

Place these files in `../KuaiRand/` (sibling of `Baselines/`):

| File | Description |
|------|-------------|
| `log_standard_4_08_to_4_21_1k_users.csv` | Interaction log |
| `user_features_1k.csv` | User side features |
| `video_features_basic_1k.csv` | Video (item) side features |

Download from: https://kuairand.com

### 2  Run the full pipeline

```bash
# CPU
bash run_all.sh

# GPU 0
bash run_all.sh 0

# GPU 0, DIN only
bash run_all.sh 0 DIN
```

Or step by step:

```bash
# Install deps
pip install fuxictr scikit-learn pandas numpy pyyaml torch

# Clone FuxiCTR
git clone https://github.com/reczoo/FuxiCTR.git

# 1. Preprocess
python step1_preprocess.py

# 2. Train both models
python step2_train.py --model both --gpu 0

# 3. Evaluate
python step3_evaluate.py --model both --gpu 0
```

## Metrics reported

For each model (DIN, BST) on each split (train, test):

| Metric | Description |
|--------|-------------|
| **Average Precision** | Area under precision-recall curve (AP/AUPRC) |
| **Log Loss** | Binary cross-entropy of predicted probabilities |
| **AUC-ROC** | Area under ROC curve |
| **Samples** | Total number of rows in the split |
| **Positive Samples** | Rows where `is_click == 1` |

Results are printed as a table and saved to `./results/evaluation_results.csv`.

## Config quick-reference

### Dataset (`config/dataset_config.yaml`)

Key parameter: `hist_video_ids`
- `type: sequence` — tells FuxiCTR to treat this as a behaviour sequence
- `max_len: 50` — truncate / pad history to 50 items
- `share_embedding: video_id` — history tokens share an embedding table with
  the target item, which is essential for DIN attention and BST cross-attention

### DIN (`config/model_config.yaml` → `DIN_kuairand_1k`)

| Parameter | Value | Note |
|-----------|-------|------|
| `din_sequence_field` | `hist_video_ids` | history to attend over |
| `din_target_field` | `video_id` | query for attention |
| `din_attention_hidden_units` | `[64]` | attention MLP size |
| `hidden_units` | `[512, 256, 128]` | DNN head |
| `embedding_dim` | `16` | shared embedding size |
| `batch_size` | `4096` | adjust for memory |

### BST (`config/model_config.yaml` → `BST_kuairand_1k`)

| Parameter | Value | Note |
|-----------|-------|------|
| `bst_sequence_field` | `hist_video_ids` | sequence input |
| `bst_target_field` | `video_id` | appended to sequence |
| `transformer_layers` | `2` | stacked transformer blocks |
| `num_heads` | `4` | multi-head attention |
| `seq_pooling_type` | `target` | use target-position output |
| `use_position_emb` | `True` | encode temporal order |
| `batch_size` | `2048` | smaller due to transformer memory |

## Evaluation scripts

### `step3_evaluate.py` (primary)
Uses FuxiCTR's Python API to load the trained model and run inference
directly — gives complete metrics on both train and test.

### `step3b_evaluate_standalone.py` (fallback)
Does not import FuxiCTR internals. Instead it:
1. Calls `run_expid.py --test_only` to produce a prediction CSV
2. Parses the training log for logloss / AUC
3. Computes all five metrics from the saved predictions via scikit-learn

Use this if you have import path issues or want to evaluate offline.
